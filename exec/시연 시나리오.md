# 🤖 RoboEditor 시연 시나리오

로봇 설정·프로젝트 파일을 **백업 → 수정 → 비교 → 적용**하는 전체 흐름을 시연자가 단계별로 따라갈 수 있도록 구성한 가이드입니다.

---

## 1. 시뮬레이션 동작 확인 (Simulation Check)

### 🎯 목표
현재 로봇이 정상적으로 동작 중임을 확인한다.

### 📺 화면
**외부 시뮬레이터**

### 📝 설명
“먼저 시뮬레이션 환경에서 로봇이 기존 설정대로 정상적으로 동작하는지 확인하겠습니다.”

### ▶ 동작
- 시뮬레이터 화면을 보여주며 로봇의 기존 동작 확인

---

## 2. 설정 파일 백업 (Backup Process)

### 🎯 목표
제어기의 workspace 데이터를 로컬 PC로 가져온다.

### 📺 화면
**RoboEditor 메인 화면 → 상단 NavDock**

### ▶ 단계

#### 2-1. 백업 메뉴 실행
- NavDock에서 **‘백업하기(Backup)’** 버튼 클릭  
  📢 설명:  
  “수정을 시작하기 전, 제어기의 최신 설정을 백업합니다.”

#### 2-2. BackupPage 팝업
- 좌측 **Select Controller**  
  - 백업할 제어기 체크 (예: `SN12345`)  
  - 설명: “백업할 대상을 선택합니다.”

- 우측 **Target Directory**  
  - `Browse...` → 저장 폴더 선택 (예: `C:/backup`)

- 하단에서 **Confirm** 클릭  
  📢 설명:  
  “선택한 디렉터리에 workspace가 압축되어 전송됩니다.”

#### 2-3. 백업 진행
- ProgressDialog가 100%가 되면 성공 메시지 확인 후 닫기

---

## 3. 파일 열기 및 수정 (Open & Modify)

### 🎯 목표
백업된 파일을 열고 설정 값을 수정한다.

### 📺 화면
**RoboEditor 좌측 패널(CenterStack)**

### ▶ 단계

#### 3-1. Workspace 트리에서 파일 열기
- 좌측 트리에서 방금 백업한 폴더(SN + 시간) 확장
- 수정할 파일 (`.yaml`, `.py`, `.srl` 등) 더블 클릭

#### 3-2. 에디터에서 수정
- 중앙 CodeEditor에 파일이 열림  
  📢 설명:  
  “이곳에서 로봇의 설정 파일을 편집할 수 있습니다.”

- 속도, 좌표 등 수치 변경
- **Ctrl + S** 저장

---

## 4. 파일 및 폴더 비교 (Compare & Folder Diff)

### 🎯 목표
수정 전·후의 차이를 파일 단위, 폴더 단위로 모두 확인한다.

### 📺 화면
**RoboEditor NavDock → ComparePage**

### ▶ 단계

#### 4-1. 비교 모드 진입
- NavDock에서 **‘비교하기(Compare)’** 클릭  
  📢 설명:  
  “수정된 내용이 정확한지 비교하기 위해 모드를 전환합니다.”

#### 4-2. ComparePage 화면
- 좌측: 수정 중인 파일  
- 우측: 비교 대상 파일 선택 영역

#### 4-3. 폴더 비교 실행
- 상단의 **‘Compare Folders’ 클릭**
  - **Left Folder**: 방금 수정한 폴더  
  - **Right Folder**: 백업된 원본 폴더  
  📢 설명:  
  “워크스페이스 전체 변경 내역을 한 번에 확인할 수 있습니다.”

#### 4-4. 결과 확인
- DiffTablePanel에서  
  - Added / Modified / Removed 항목 리스트 표시
- Modified 항목 더블 클릭 → 상세 Diff 화면 표시  
  📢 설명:  
  “변경된 라인을 색상으로 하이라이트해 직관적으로 확인할 수 있습니다.”

---

## 5. 적용하기 (Apply Process)

### 🎯 목표
수정된 설정을 제어기에 다시 적용한다.

### 📺 화면
**RoboEditor → ApplyPage**

### ▶ 단계

#### 5-1. Apply 실행
- NavDock에서 **‘적용하기(Apply)’ 클릭**

#### 5-2. ApplyPage 설정
- 좌측 **Select Backup**: 수정한 백업 선택
- 우측 **Select Controller**: 적용 대상 체크
- 하단 **Apply** 버튼 클릭

#### 5-3. 비밀번호 인증
- PasswordManager 팝업  
  - 관리자 비밀번호 입력  
  📢 설명:  
  “보안 강화를 위해 관리자 인증을 진행합니다.”

#### 5-4. 최종 확인
- ConfirmSelection 팝업 확인 → Apply 클릭

#### 5-5. 적용 진행
- ProgressDialog가 완료되면 “적용 성공” 메시지 확인

---

## 6. 시연 종료 (Conclusion)

### 설명
“적용이 성공적으로 끝났습니다. 이제 시뮬레이터에서 변경된 설정이 반영되었는지 확인해 보겠습니다.”

### 동작
- 다시 시뮬레이터 화면으로 전환  
- 변경된 동작 확인
